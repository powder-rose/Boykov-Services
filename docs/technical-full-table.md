# Полная таблица в Boykov-services — патч интерфейса

## Что меняется

* В разделе «Техотдел» отображаются ВСЕ столбцы всех семи вкладок из таблицы «ДОП.РАБОТЫ», а не краткая выборка.
* Первая вкладка «СЭР ТО МСК РЕГИОНЫ»: закреплены «Код объекта» и «Наименование компании»; остальные столбцы оригинала идут далее в исходном порядке. «Комментарии Ирины» показываются отдельным защищённым столбцом из бухгалтерии.
* На остальных вкладках закреплены первые два исходных столбца, не удаляя остальные.
* Горизонтальная и вертикальная прокрутка внутри таблицы; видимые кнопки «Левее» и «Правее» под таблицей, доступны прокрутка мышью/тачпадом и клавиатурой.
* В редактируемых рабочих ячейках нажатие открывает карточку с редактором. Защищённые поля не редактируются. Заметки, подпись автора и история остаются.

## Источники данных

Техническая таблица: `https://docs.google.com/spreadsheets/d/1-1F68x3sE3uxknDMJEGlc6YtuJ9YgsDRqJutofJdoL4/edit?gid=723255987`.

Все исходные **значения** ячеек (в том числе столбцы с пустыми названиями) считывает существующий Apps Script `boykovTechRead_()` и передаёт в хранилище через `/hooks/technical/import/*`. Это обновление НЕ меняет Apps Script, серверную базу и способ загрузки. Сохраняется разделение: 10 полей из бухгалтерии при однозначном совпадении кода → только чтение; всё остальное из «ДОП.РАБОТЫ» → рабочие данные. Исходное форматирование, комментарии Google Sheets, формулы как формулы и вложенные изображения не копируются: сервис получает отображаемые значения ячеек.

**Если на экране пока 0 записей**, патч интерфейса сам данные не загрузит. Вначале нужно развернуть серверный модуль приёма данных на HTTPS VPS и выполнить `boykovTechPushNow` в Apps Script; ответ `Cannot POST /hooks/technical/import/start` означает, что маршрут не развёрнут на сервере. Не публикуйте Google Таблицы в открытый доступ.

## Установка на Windows

В PowerShell из `Downloads`:

```powershell
$zip = "$env:USERPROFILE\Downloads\Boykov-services_Tech_Full_Table_Patch.zip"
$dir = "$env:USERPROFILE\Downloads\Boykov-services_Tech_Full_Table_Patch"
Expand-Archive -LiteralPath $zip -DestinationPath $dir -Force
cd $dir
node .\apply-update.mjs "C:\Users\user\WebstormProjects\boykov-services"
```

Инсталлятор перед записью проверяет, что предыдущий UI-патч установлен без изменений. Если файлы вручную редактировались, он остановится с `VERSION_MISMATCH`, не перезаписывая изменения. Старые версии сохраняются в `%USERPROFILE%\boykov-services-backups`. `.env`, `data`, GitHub, Google и сервер не изменяются.

Далее:

```powershell
cd "C:\Users\user\WebstormProjects\boykov-services"
npm run check
npm run dev
```

Проверьте переход по вкладкам, горизонтальную прокрутку, закрепление двух колонок, открытие карточки и заметки. Для реального теста с данными сначала нужна успешная серверная интеграция Apps Script.
