# Boykov-services — обновление интерфейса «Техотдел»

## Что меняется

- Убраны три лишние карточки со статистикой и нижняя панель входа.
- Поиск и фильтры приведены к одной компактной строке, таблица показывает важные сведения, остальные поля доступны в боковой карточке.
- Все семь вкладок из «ДОП.РАБОТЫ» сохраняются.
- **Отдельный личный вход в раздел «Техотдел» больше не нужен.** Любой, кто уже вошёл в Boykov-services по общему паролю, может добавить заметку и изменить доступное рабочее поле.
- Поле «Автор» необязательное: если оставить пустым, запись будет помечена «Без подписи». Имя — введённое вручную, система не подтверждает его принадлежность пользователю.
- Синхронизируемые бухгалтерские поля остаются заблокированы на сервере. Заметки и рабочие изменения не отправляются в Google.
- Синхронизация по Apps Script и токен TECH_PUSH_IMPORT_TOKEN не изменяются.

## Установка в Windows PowerShell

1. Скачайте архив и распакуйте его в папку `Загрузки` (`Downloads`).
2. Откройте PowerShell в папке распакованного архива и выполните:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\apply-update.ps1 -ProjectPath "C:\Users\user\WebstormProjects\boykov-services"
```

Альтернатива без PowerShell-обёртки:

```powershell
node .\apply-update.mjs "C:\Users\user\WebstormProjects\boykov-services"
```

3. Успешное выполнение пишет `TECH_UX_PATCH_INSTALLED=YES` и путь `BACKUP=...`.
4. Проверьте сборку и тесты:

```powershell
cd "C:\Users\user\WebstormProjects\boykov-services"
npm run check
npm run dev
```

## Безопасность

Установщик проверяет контрольные суммы ровно трёх ранее установленных файлов. Если файлы отличаются, он останавливается без записи: это защита от потери ручных исправлений. Перед заменой создаёт отдельную резервную копию в папке `boykov-services-backups` домашнего каталога Windows.

Патч не меняет `.env`, Google Apps Script, токены, SQLite и Git; не выполняет публикацию на VPS. Новые функции авторства требуют обновления и frontend, и backend. Сервис продолжает требовать **основной вход в Boykov-services** — доступа без общего пароля не появляется.

## Проверка после установки

1. Вкладки (7 шт.) на месте; сверху нет трёх статистических карточек, снизу нет «Войти в профиль».
2. В карточке объекта можно сохранить заметку с именем или без имени (в истории — «Без подписи»).
3. Вручную меняется только рабочее поле, бухгалтерская стоимость не редактируется.
4. После синхронизации Apps Script заметки и рабочие изменения сохраняются.
5. Оба источника Google остаются защищёнными: Boykov-services не записывает в них изменения.

Если появится `VERSION_MISMATCH`, пришлите этот вывод и текущие файлы `src/pages/Technical.tsx`, `server/modules/technical/index.js`, `src/pages/technical.css`; не заменяйте файлы вручную.
