Проверено 16 ноября 2026 года.

| Проверка | Результат |
| --- | --- |
| TypeScript и production-сборка Vite | Успешно |
| API, вход, сессии, защита файлов и Wordstat | 13 тестов, успешно |
| Python-сервис, все пять исходных DOCM-шаблонов | 8 тестов, успешно |
| Браузер: вход → договор → скачивание DOCM | Успешно, реальное заполнение шаблона на тестовых реквизитах |
| Браузер: Wordstat → Excel | Успешно с подменой внешнего Wordstat API на синтетический ответ |

| Исключения Git | Настоящие env, data, SQLite, зависимости и результаты исключены |

Вызовы реального YandexGPT / OCR и Wordstat с рабочими ключами не выполнялись: пользовательские env находятся на компьютере владельца. В тестах распознавание проверено через адаптер исходного ядра с подменённым ответом, а формирование всех DOCM выполнялось реально.

Docker-файлы и GitHub Actions подготовлены. Docker Engine в среде разработки не установлен; локальная сборка контейнеров и развёртывание на VPS не выполнялись. Отдельная CI-задача соберёт оба образа после push в GitHub.

Новый GitHub-репозиторий и домен этим проектом автоматически не создаются. Инструкция первого push находится в README.md; инструкция production-развёртывания — в DEPLOY.md.
