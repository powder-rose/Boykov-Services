# Boykov Services — общая статистика сайтов

Патч для main 16063d3 или совместимой версии.

В разделе «Статистика» добавлена вкладка «Все сайты» с общими показателями, цветными тегами и линиями каждого сайта. Клик по тегу включает/скрывает сайт, пересчитывает суммы и таблицу. Цвет закреплён за сайтом для всей команды. Показатели — визиты, просмотры, статьи и заявки; периоды 24 часа/7/30/90 дней. График работает по интервалам или накопительно, поддерживает указатель и клавиатуру. Из таблицы можно открыть прежний подробный отчёт выбранного сайта с тем же периодом.

Существующие каналы статистики используются без изменений. Сайты без посещаемости отмечаются «Нет данных»; устаревшие источники исключаются из сумм с предупреждением. Данные не подменяются нулями. Новых внешних счётчиков этот патч не устанавливает.

## PowerShell в корне локального проекта

Сохраните ZIP в Downloads:

```powershell
$zip = Join-Path $env:USERPROFILE 'Downloads\Boykov-services_Statistics_Overview_Patch.zip'
Expand-Archive -LiteralPath $zip -DestinationPath .\_patch-statistics-overview -Force
powershell -ExecutionPolicy Bypass -File .\_patch-statistics-overview\Install-Patch.ps1
```

Установщик проверяет применимость, сохраняет копии изменяемых файлов в .git/boykov-patch-backups, накладывает патч и запускает npm run check. Требуется Node.js 24. Повторный запуск не накладывает уже установленный патч снова, но повторяет проверки. Коммитов и push не делает. После PATCH_CHECK=OK закоммитьте файлы из FILES.txt и выполните push обычным способом. Архив и каталог _patch-statistics-overview в Git добавлять не нужно.

## После push — VPS Boykov Services

```bash
cd /opt/boykov-services
git pull --ff-only
bash scripts/deploy-statistics-overview.sh
```

Скрипт сохраняет проверенный снимок SQLite и предыдущий образ приложения, обновляет только app, проверяет healthy, новую таблицу цветов и авторизацию API. Ожидается STATISTICS_OVERVIEW_DEPLOY=OK. Коннекторы и сервис документов не перезапускаются; дополнительных ключей и cron нет. На VPS сайтов этот патч устанавливать не нужно.

BACKUP указывает каталог с предыдущим образом, путём резервной базы и rollback-app.sh. Откат приложения — bash <BACKUP>/rollback-app.sh. Всю базу автоматически не заменять: после снимка могли поступить новые заявки.

## Правила статистики

Общие суммы относятся только к выбранным сайтам и доступным показателям; число источников показано в каждой карточке. Native-заявки и их копии в сервисе повторно не складываются. У сайта без native-отчёта учитываются только центральные заявки, как в прежнем отчёте. Визиты между доменами не считаются уникальными людьми.

Время срезов у сайтов может различаться. Их фактические значения не интерполируются; график совмещает часовые/дневные корзины по Москве. Крайние интервалы могут быть неполными, а общая рамка 24-часовых срезов может отличаться на несколько минут. Накопительный режим показывает сумму с начала отчёта сайта, не процент роста к предыдущему периоду. Точные границы и время обновления доступны на экране.

Подробная документация после установки: docs/STATISTICS-OVERVIEW.md.

Проверено: TypeScript/Vite, 9 новых проверок (все успешны); полный набор — 183 успешны, 13 существующих интеграционных проверок пропущены по условиям окружения, ошибок нет. В браузере проверены фильтрация и цвета линий/тегов, смена показателя, накопительный режим, выбор даты клавишами, пустой выбор, переход в подробный отчёт и возврат с сохранением режима. Синтаксис деплоя проверен bash -n. Фактический запуск на VPS выполняется пользователем после push.
