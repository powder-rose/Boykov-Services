# Удаление клиентов BoykovDocs

Патч к установленному разделу «Клиенты BoykovDocs», основа main e10a59f. Шесть файлов, без новых зависимостей и ключей. Самостоятельно клиентов не удаляет.

В карточке добавлена кнопка «Удалить» с подтверждением имени, контакта и ID. После подтверждения «В корзину» карточка исчезает из рабочего списка, поиска и счётчиков. В разделе есть «Корзина» и «Восстановить». Компания, история звонков и исходный ID пользователя сохраняются. Видно имя сотрудника и время удаления; общий вход подписывается «Общий доступ». Журнал удаления и восстановления хранится на сервере. Новые данные и повторные события синхронизации не возвращают карточку в активный список; при восстановлении видны актуальные данные. Учётная запись на BoykovDocs продолжает действовать.

## PowerShell — локальный проект

Сохраните ZIP в «Загрузки». В корне boykov-services:

```powershell
Expand-Archive -LiteralPath "$env:USERPROFILE\Downloads\Boykov-services_Docs_Customers_Delete_Patch.zip" -DestinationPath .\_patch-docs-delete -Force
powershell -NoProfile -ExecutionPolicy Bypass -File .\_patch-docs-delete\Install-Patch.ps1
```

Установщик сначала проверяет совместимость всех правок, сохраняет копии затронутых файлов в резервных копиях Git, применяет патч и запускает npm run check. Повторный запуск также проверяет проект. Нужен Node.js 24. Коммит и push не выполняются автоматически. Папку _patch-docs-delete не включайте в коммит.

После PATCH_CHECK=OK:

```powershell
$patchFiles = Get-Content .\_patch-docs-delete\FILES.txt
git add -- $patchFiles
git commit -m "feat: add trash and restore for BoykovDocs customers"
git push
```

## VPS Boykov Services

На сервере с /opt/boykov-services:

```bash
cd /opt/boykov-services
git pull --ff-only
bash scripts/deploy-docs-customers.sh
```

Скрипт сохраняет согласованный снимок SQLite и предыдущий образ, пересобирает только приложение, ждёт готовности и проверяет миграцию корзины и авторизацию. Выводит DOCS_CUSTOMERS_TRASH=OK и BACKUP. В каталоге BACKUP есть rollback-app.sh для отката образа с сохранением текущей базы.

На сервере BoykovDocs никаких команд выполнять не требуется: текущий коннектор и ключ продолжают работать. Дата начала загрузки 19.11.2026 00:00 по Москве сохраняется.

После обновления откройте «Клиенты BoykovDocs», выберите тестового пользователя и нажмите «Удалить» → «В корзину». Для возврата откройте «Корзина» → карточку → «Восстановить».

## Проверка

TypeScript/Vite: успешно. Все 14 тестов модуля BoykovDocs прошли, включая четыре новых сценария удаления: сохранение компании и звонков, повторная доставка и перезапуск, автор действия и права доступа, конфликты версий, повтор запроса после утраты ответа, восстановление и миграция прежней базы. Общий прогон: 150 тестов, 146 успешно, 4 существующие проверки NWD пропущены из-за отсутствия PHP/MySQL в среде. В браузере проверены отмена подтверждения, удаление, исключение из счётчиков, просмотр корзины, автор удаления, блокировка звонков в корзине и восстановление. Изменения на production не выполнялись.
