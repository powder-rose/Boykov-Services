# Boykov Services — фото в PDF и прокрутка меню

База: main 14092a0 или совместимая версия.

В техотделе появилась карточка «Фото в PDF» с отдельным рабочим окном на React/TypeScript/Vite в палитре сервиса. Фото обрабатываются только в браузере: на сервер не отправляются, в истории и базе не сохраняются. Доступны выбор/перетаскивание, предпросмотр, порядок страниц, сжатие, A4 или страницы по пропорциям фото, прогресс, отмена и скачивание. При закрытии окна выбранные фото и результат очищаются.

В боковой панели исправлена собственная вертикальная прокрутка: доступны все нижние пункты, помощь, профиль и выход, в том числе на невысоком экране.

## PowerShell в корне локального проекта

Сохраните архив в Downloads и выполните:

```powershell
$zip = Join-Path $env:USERPROFILE 'Downloads\Boykov-services_Photo_PDF_Patch.zip'
Expand-Archive -LiteralPath $zip -DestinationPath .\_patch-photo-pdf -Force
powershell -ExecutionPolicy Bypass -File .\_patch-photo-pdf\Install-Patch.ps1
```

Установщик проверяет применимость, сохраняет копии существующих изменяемых файлов внутри .git/boykov-patch-backups, накладывает патч и выполняет npm run check. Требуется Node.js 24. Повторное выполнение не накладывает уже установленный патч ещё раз, но повторяет проверки. Коммитов и push не делает. После PATCH_CHECK=OK закоммитьте файлы из FILES.txt и отправьте изменения привычным способом. Архив и каталог _patch-photo-pdf в Git добавлять не нужно.

## После push — VPS Boykov Services

```bash
cd /opt/boykov-services
git pull --ff-only
bash scripts/deploy-photo-pdf.sh
```

Обновляется только app; сервис документов и коннекторы не перезапускаются. Скрипт сохраняет предыдущий образ и rollback-app.sh в выведенном BACKUP, ждёт healthy, проверяет HTTP, CSP и сборку worker. Ожидается PHOTO_PDF_DEPLOY=OK. Никаких дополнительных сервисов, миграций, ключей или cron не нужно.

## Параметры

До 500 фото, до 50 МБ каждое; JPG, PNG, WEBP, BMP, AVIF. HEIC/HEIF — при поддержке декодером браузера. Качество JPEG 35–95%, сторона 1200/1600/2200/3000 px или исходная, без увеличения маленьких снимков. Прозрачность заменяется белым фоном; ориентация камеры учитывается. PDF до 250 МБ, большие наборы лучше делить. Сжатие не гарантирует уменьшение уже компактного исходника — показываются реальные размеры.

Полная документация после применения: docs/PHOTO-PDF.md.

Проверено: TypeScript/Vite; 7 новых автоматических проверок; полный набор — 174 успешны, ошибок нет, 13 существующих интеграционных проверок пропущены по условиям окружения. В браузере проверены реальный PDF, оба режима страниц, сортировка/перестановка, повреждённый снимок, отмена обработки 80 фото, очистка при закрытии и доступность выхода после прокрутки меню. Скачанный PDF проверен pdfinfo и отрисован pdftoppm: 4 страницы, корректная ориентация, белый фон PNG, без ошибок рендера.

Фактический деплой на VPS выполняется пользователем; здесь подготовлены код, проверенный патч и команды. Исходный HTML-референс не изменён.
