# Boykov Services — подсказки на общем графике

Патч для main 465969f (feat: patch statistics overview) или совместимой версии.

При наведении на график появляется карточка с датой по Москве, выбранным показателем, названиями сайтов, цветными маркерами и точными значениями. Карточка обновляется при движении указателя, учитывает выбранные сайты и накопительный режим. Ноль отображается как 0, отсутствие данных — как прочерк. Для неполных интервалов выводится пояснение.

Поддерживаются стрелки влево/вправо, Home/End и Escape. Касание выбирает интервал на сенсорном экране; в узком блоке карточка располагается под графиком. Точная расшифровка интервалов остаётся под ним.

## Установка в PowerShell в корне локального проекта

Сохраните ZIP в Downloads:

```powershell
$zip = Join-Path $env:USERPROFILE 'Downloads\Boykov-services_Statistics_Tooltip_Patch.zip'
Expand-Archive -LiteralPath $zip -DestinationPath .\_patch-statistics-tooltip -Force
powershell -ExecutionPolicy Bypass -File .\_patch-statistics-tooltip\Install-Patch.ps1
```

Установщик проверяет применимость, сохраняет копии затронутых файлов в .git/boykov-patch-backups, накладывает патч и запускает npm run check. Требуется Node.js 24. Повторный запуск проверяет уже установленный патч и снова запускает проверки. Установщик не делает коммит и push. После PATCH_CHECK=OK закоммитьте файлы из FILES.txt и выполните push обычным способом. Архив и каталог _patch-statistics-tooltip в Git добавлять не нужно.

## После push — VPS Boykov Services

```bash
cd /opt/boykov-services
git pull --ff-only
bash scripts/deploy-statistics-overview.sh
```

Используется уже установленный скрипт деплоя общей статистики. Он сохраняет резервную копию SQLite и предыдущий образ приложения, обновляет app и проверяет healthy/авторизацию API. Ожидается STATISTICS_OVERVIEW_DEPLOY=OK. На серверах сайтов ничего устанавливать не требуется; настройки подключений и cron не меняются.

BACKUP содержит rollback-app.sh для отката приложения. Не заменяйте базу автоматически: после создания резервной копии могли поступить новые данные.
