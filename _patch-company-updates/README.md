# Обновления компаний и точки в заголовках

Патч для Boykov Services с установленными карточками BoykovDocs и корзиной клиентов. Основа main d8a8072. Девять файлов, без новых зависимостей и ключей. Изменений на production пока не выполнялось.

## Что меняется

Реальные изменения компании создают пометку «Обновлено». В стандартной сортировке непросмотренные изменения идут в начало списка, самые свежие — первыми; это работает и при разбиении на страницы. Над списком появляется розовый виджет с количеством компаний и временем последнего изменения. «Показать обновлённые» и «Только обновления» позволяют оставить только такие карточки. Явный выбор «Сначала ранние» сохраняет хронологическую сортировку.

В карточке указаны время обновления и изменённые поля; поля выделены розовым акцентом. Кнопка «Просмотрено» подтверждает именно текущую версию компании. У каждого персонального аккаунта своё состояние просмотра; общий доступ имеет общее состояние. Простое открытие карточки не снимает пометку. Следующее изменение вновь создаёт уведомление. Устаревшая кнопка не скрывает новую версию, пришедшую во время просмотра.

Первичное заполнение, повтор доставки, изменение контактов и неизменившиеся реквизиты не создают ложных уведомлений. Очередь может доставлять снимки не по порядку: актуальная компания сохраняется, а более ранний снимок позволяет подтвердить изменение без возврата старых реквизитов. Уже сохранённая история проверяется один раз при обновлении: подтверждённые прежние изменения также появятся в виджете. Промежуточные изменения, которые коннектор не успел получить, восстановить нельзя.

Карточки из корзины остаются в корзине. Звонки, авторы и история сохраняются. Дата начала загрузки 19.11.2026 00:00 по Москве остаётся прежней.

Во всех главных заголовках разделов рабочего пространства добавлена та же розовая точка, что в техотделе: общий компонент, цвет #c77796, размер наследуется от заголовка. Декоративная точка скрыта от экранных дикторов. Страница входа и второстепенные заголовки карточек не меняются.

## Установка в PowerShell

Сохраните ZIP в «Загрузки». В корне локального проекта:

```powershell
Expand-Archive -LiteralPath "$env:USERPROFILE\Downloads\Boykov-services_Company_Updates_Patch.zip" -DestinationPath .\_patch-company-updates -Force
powershell -NoProfile -ExecutionPolicy Bypass -File .\_patch-company-updates\Install-Patch.ps1
```

Установщик проверяет совместимость до применения, сохраняет копии затронутых файлов в резервных копиях Git и запускает npm run check. Повторный запуск также выполняет проверки. Нужен Node.js 24. Коммит и push выполняются самостоятельно. Папку _patch-company-updates в коммит не добавляйте.

После PATCH_CHECK=OK:

```powershell
$patchFiles = Get-Content .\_patch-company-updates\FILES.txt
git add -- $patchFiles
git commit -m "feat: highlight company updates and unify section title dots"
git push
```

## VPS Boykov Services

```bash
cd /opt/boykov-services
git pull --ff-only
bash scripts/deploy-docs-customers.sh
```

Скрипт создаёт согласованный снимок SQLite и сохраняет прежний образ, обновляет только app, ждёт готовности и проверяет новые таблицы. Результат: DOCS_CUSTOMERS_UPDATES=OK. Путь BACKUP содержит rollback-app.sh для отката образа с сохранением текущей базы. Контейнер документов не перезапускается. На сервере BoykovDocs ничего менять не требуется; существующий коннектор и ключ работают дальше.
